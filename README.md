# EDA Microdados ENEM 2025
O objetivo desse projeto é aplicar os conhecimentos adquiridos sobre análise exploratória de dados (EDA) utilizando os Microdados do ENEM de 2025.

Os dados foram obtidos através da página do ENEM no site do INEP e podem ser baixados [aqui](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/enem).
### Tecnologias utilizadas
* Python
* Pandas
### Dados
Os microdados se constituem no menor nível de desagregação de dados recolhidos por pesquisas, avaliações e exames realizados.

O conjunto de Microdados do ENEM é composto por três arquivos, são eles:
* **PARTICIPANTES_2025.csv**: informações gerais sobre a caracterização dos participantes e da escola que ele declarou ter frequentado.
* **RESULTADOS_2025.csv**: informações gerais sobre a realização das provas e as notas das provas objetivas e da redação.
* **ITENS_PROVA_2025.csv**: informações gerais sobres os itens (questões) das provas.

Cada base de dados possui um dicionário que descreve com detalhes os campos existentes.
### Levantamentos iniciais
Devido a falta de familiaridade com os dados, primeiro foi necessário entender melhor sua composição, ou seja, compreender com mais detalhes os dados contidos dentro de cada arquivo, se os arquivos se relacionam entre si de forma que possibilite o cruzamento entre as bases, além de investigar a necessidade de realizar algum tipo de limpeza ou tratamento nos dados existentes.

Com isso em mente e com o auxílio do dicionário de dados foi realizada uma análise individual de cada arquivo.
